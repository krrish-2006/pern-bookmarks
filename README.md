# PERN Bookmark Manager

A full-stack bookmark manager application where users can save, categorize, and manage their favorite websites.

## 🚀 Live Demo
[Click here to view the live app](https://pern-bookmarks.vercel.app)

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** PostgreSQL (hosted on Supabase)
- **Deployment:** Vercel (Frontend), Render (Backend)

## ✨ Features
- Add new bookmarks with a title, URL, and category.
- View a list of all saved bookmarks.
- Delete bookmarks.
- Relational database setup (One-to-Many: Categories to Bookmarks).
- Responsive UI styled with Tailwind CSS.
